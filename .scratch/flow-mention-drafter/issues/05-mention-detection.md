## Question

[Flow 알림 API 실호출로 멘션 데이터 확인](01-flow-alarm-api-check.md)의 결과를 바탕으로, 앱이 멘션을 **어떻게 수집하고 추적할지** 정한다.

- **채팅 멘션**: MVP에 넣을지 정한다. 알림 API에 채팅 멘션이 없으면 대안 경로를 쓸지, 아니면 범위에서 뺄지도 정한다.
- **폴링**: 주기와 커서를 어떻게 쓸지 정한다. 앱이 꺼져 있던 동안 쌓인 멘션을 어디까지 거슬러 가져올지도 정한다.
- **중복 방지**: 같은 멘션을 두 번 처리하지 않는 기준(무엇을 멘션의 정체성으로 볼지)을 정한다.
- **읽음 상태**: Flow의 읽음 상태를 앱이 바꿀지, 건드리지 않을지 정한다.
- **맥락 수집 범위**: 스레드가 길 때 게시물 본문과 댓글 중 어디까지 가져올지 정한다.
