## Question

ad-hoc 서명만 한 최소 Tauri v2 앱이 이 Mac에서 실제로 동작하는지 확인한다. 최소 앱에는 트레이 아이콘, 알림, 로그인 시 자동 시작만 넣는다. 문서로는 확정할 수 없었던 항목들이라, [데스크톱 프레임워크와 기술 스택 결정](08-desktop-stack.md)과 "알림을 클릭하면 검토 화면이 열린다"는 전제가 이 결과에 달려 있다.

1. **설치 경로**: 브라우저로 내려받은 DMG(quarantine 속성이 붙은 상태)를 열 때 어느 쪽으로 가는가? "그래도 열기"로 넘어갈 수 있는 경로인가, "손상됨"으로 막히는 경로인가?
2. **알림 표시**: 알림이 뜨는가? `NSUserNotification` 기반이다.
3. **알림 클릭**: 알림을 클릭한 사실이 앱에 전달되는가? 알림 플러그인 2.6.0 이상에서 확인한다.
4. **자동 시작**: 로그인 시 자동 시작(LaunchAgent)이 동작하는가?
5. **비교 (선택)**: 같은 조건에서 ad-hoc 서명한 Electron 42 이상 앱은 알림을 띄울 수 있는가? 즉 ad-hoc 서명이 Electron의 "코드 서명 필요" 조건을 만족하는가?

## 체크리스트

- 최소 앱 코드는 이 지도의 `prototypes/` 아래에 둔다. 구현 코드로 재사용하지 않는다.
- 결과를 `## Answer`에 기록한다. 항목마다 macOS 버전, 칩(Apple Silicon/Intel), 실제로 본 대화상자나 알림 화면 설명을 남긴다.
