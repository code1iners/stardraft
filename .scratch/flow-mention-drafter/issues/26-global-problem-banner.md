# 26: 전역 문제 표시

**Spec:** [스펙](../spec.md) 13절 "전역 문제의 표시", 8절 "트레이"

**What to build:** 감지를 멈추는 문제가 생기면 트레이 아이콘에 "!"가 뜨고, 작은 창 맨 위 띠에 원인과 행동 버튼이 보이며, 오른쪽 클릭 메뉴 맨 위에 같은 항목이 생기고, OS 알림이 한 번 뜬다. 첫 사용처는 "키 확인 필요"다. 저장된 키를 읽을 수 없거나 Flow가 `401`을 주면 이 표시가 나타나고, 키를 다시 넣어 해결되면 사라진다.

**Blocked by:** 25

**Status:** ready-for-agent

- [ ] 전역 문제는 core의 상태로 관리되고 원인마다 하나다(키 확인 필요·CLI 없음·미로그인·CLI 업데이트 필요·점검 실행 실패는 뒤 티켓이 더한다).
- [ ] 트레이 "!"는 macOS는 아이콘 옆 글자, Windows는 아이콘에 그린 빨간 배지이며, 검토 대기 숫자보다 앞선다.
- [ ] 작은 창 띠 자리는 하나다. 문구: `401` "Flow가 키를 거부했습니다. 키가 삭제됐거나 바뀌었을 수 있습니다." / 복호화 실패 "저장된 키를 읽을 수 없습니다. 키체인 접근을 거부했거나 항목이 지워졌을 수 있습니다."(Windows는 DPAPI 문구). 버튼 [키 다시 입력]은 설정 창의 Flow 계정 칸을 연다.
- [ ] 오른쪽 클릭 메뉴 맨 위에 같은 항목이 있고 누르면 같은 곳으로 간다.
- [ ] OS 알림은 같은 원인으로는 해결되기 전까지 다시 띄우지 않고, 해결된 뒤 다시 생기면 다시 띄운다. 알림 포트로 보낸다.
- [ ] 복호화 실패(키체인 거부·항목 삭제)가 앱 시작 시 "키 확인 필요"로 이어지고, 같은 계정의 키를 다시 넣으면 상태가 이어진다.
- [ ] 가짜 시계·알림 포트로 "한 번만 알림"과 해제가 테스트된다.
