# 29: 작업 폴더

**Spec:** [스펙](../spec.md) 5절 "작업 폴더", "후보 찾기", 13절 "작업 폴더"

**What to build:** 설정 창 "저장소" 칸에서 "폴더 추가…"로 작업 폴더를 여러 개 고르면, 앱이 바로 훑어 "저장소 12개"처럼 보여 주고 펼치면 저장소 이름이 나온다. 홈 폴더 아래 흔한 이름의 폴더를 "이 PC에서 찾은 폴더"로 제안한다.

**Blocked by:** 24

**Status:** ready-for-agent

- [ ] OS 폴더 선택 창으로 여러 개를 한 번에 고를 수 있고, 경로는 OS 고유 형식의 절대 경로로 `settings.json`에 저장된다.
- [ ] 후보 찾기 규칙: 최대 3단계 깊이의 `.git` 디렉터리 또는 worktree의 `.git` 파일, 저장소 안으로는 내려가지 않음, 숨김 폴더와 `node_modules` 건너뜀, 고른 폴더 자체가 저장소면 그 하나. 0개면 경고하되 추가는 막지 않는다.
- [ ] 네트워크 경로(`\\server\share`)와 WSL 경로(`\\wsl.localhost\...`)는 이유를 보여 주고 받지 않는다.
- [ ] `~/workspace`, `~/projects`, `~/dev`, `~/code`, `~/src`, `~/IdeaProjects` 등 가운데 저장소가 든 폴더를 "이 PC에서 찾은 폴더"로 보이고 [추가]를 단다.
- [ ] 후보 찾기는 임시 디렉터리에 가짜 저장소를 만들어 테스트된다.
