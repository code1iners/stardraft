# 30: 저장소 매핑

**Spec:** [스펙](../spec.md) 5절 "저장소 매핑"

**What to build:** 설정 창 "저장소" 칸의 저장소 매핑 목록에서 참여 Flow 프로젝트를 고르고 폴더 선택 창으로 저장소를 여러 개 연결한다. 연결된 폴더가 사라지면 목록에 표시된다.

**Blocked by:** 25, 29

**Status:** ready-for-agent

- [ ] 참여 Flow 프로젝트 목록은 `GET /user/projects/participants`(`projectId`, `title`, `projectUrl`)로 가져온다. 매핑 키는 `projectId`다.
- [ ] Flow 프로젝트 하나에 저장소를 개수 제한 없이 연결하고 추가·수정·삭제할 수 있다. git 저장소가 아닌 코드 폴더도 직접 넣을 수 있다.
- [ ] 작업 폴더를 지워도 그 안을 가리키는 매핑은 그대로 남는다.
- [ ] 연결된 폴더 중 하나라도 없으면 목록에 "폴더를 찾을 수 없음"으로 표시된다(묶음 처리에서의 의미는 35).
- [ ] 가짜 `fetch`로 목록 조회가, 임시 디렉터리로 사라진 폴더 표시가 테스트된다.
