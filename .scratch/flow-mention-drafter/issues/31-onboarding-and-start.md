# 31: 첫 실행 온보딩과 감지 시작

**Spec:** [스펙](../spec.md) 13절 "첫 실행의 흐름", 8절 "작은 창"의 다른 상태

**What to build:** 앱을 처음 켜면 트레이 옆 작은 창이 자동으로 뜨고 필수 세 가지(Flow 개인 API 키, 에이전트, 작업 폴더)의 상태를 보여 준다. 줄을 누르면 설정 창의 해당 칸이 열리고, 설정 창 맨 위 띠가 "필수 설정 n/3"을 보인다. 셋이 다 되면 [감지 시작]이 나타나고, 누르면 기준점을 잡고 "멘션 감지를 시작했습니다" 알림이 뜨며 로그인 시 자동 시작이 켜진다.

**Blocked by:** 25, 28, 29

**Status:** ready-for-agent

- [ ] 첫 실행에 작은 창이 자동으로 뜬다. 필수 설정 전 화면에는 안내 문장, 세 줄과 상태(✓/필요), [설정 열기]가 있다. 트레이에 노란 점("설정 필요")이 뜬다.
- [ ] 설정 창 첫 설정 띠에 "필수 설정 n/3", 남은 항목, 다음 항목 버튼이 있고, 칸 목록의 끝나지 않은 필수 칸에 점이 찍힌다. 감지를 시작한 뒤에는 띠가 다시 나오지 않는다.
- [ ] 중간에 닫아도 통과한 항목은 저장되어 있고, 트레이를 누르거나 다시 켜면 같은 화면이 뜬다. 순서 강제는 없다.
- [ ] [감지 시작]은 확인된 키, 에이전트 연결, 작업 폴더 1개 이상일 때만 보인다. 곁에 안내 두 줄(자동 시작, macOS 알림 허용 / Windows는 숫자 안내)이 있다.
- [ ] 누르면 알림 목록을 한 번 조회해 가장 최근 `alarmId`를 기준점으로 `state.db`에 저장하고, 설정 창을 닫고, 빈 작은 창([최근 멘션으로 시험] 자리 포함)을 띄우고, 바로 시작 알림을 띄운다.
- [ ] 로그인 시 자동 시작을 켠다(`setLoginItemSettings`). 설정 "일반"에 토글 자리를 둔다.
- [ ] Windows 첫 실행 작은 창에 숨김 영역 안내 문구가 있다.
- [ ] 가짜 포트로 "세 가지 전/후" 전환과 기준점 저장이 테스트된다.
