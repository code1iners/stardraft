# 34: 맥락 조회와 길이 상한

**Spec:** [스펙](../spec.md) 4절 "맥락 수집"

**What to build:** 묶음마다 에이전트에게 넘길 맥락(게시물 제목·본문, 대상 댓글 스레드 전부, 다른 댓글 최근 20개)을 Flow에서 새로 조회해 하나의 문서로 만들고 비교 기준으로 저장한다. 작은 창 원문 영역의 "스레드 보기"로 앞선 글을 펼쳐 볼 수 있다.

**Blocked by:** 33

**Status:** ready-for-agent

- [ ] 본문은 `content` JSON의 TEXT 컴포넌트에서 꺼내고, 첨부는 파일 이름만, 이미지는 넣지 않는다. 대상 댓글 스레드는 대댓글 API로 끝까지 가져온다. 다른 댓글은 최근 20개, 댓글마다 대댓글 처음 10개.
- [ ] `systemCode`가 있는 시스템 댓글은 맥락에 넣지 않고 20개 집계에도 세지 않는다.
- [ ] `@[이름](ID)` 표기를 이름 표기로 바꾼다. Flow 사용자 ID는 문서에 들어가지 않는다.
- [ ] 30,000자 상한과 빼는 순서(다른 댓글의 대댓글 → 다른 댓글 → 댓글 스레드 묶음의 본문 앞 10,000자 → 대상 스레드의 비멘션 대댓글), 절대 빼지 않는 것, "[다른 댓글 12개 생략]" 표시, 뺀 항목 수 기록.
- [ ] 조회 결과를 비교 기준으로 묶음에 저장한다(변화 감시는 45). 조회는 초안을 만들 때마다 새로 한다.
- [ ] 원문 영역의 "스레드 보기"가 맥락의 앞선 글을 펼친다.
- [ ] 가짜 응답으로 수집 범위, 페이지 넘김, 자르기 순서와 표시, 표기 변환이 테스트된다.
