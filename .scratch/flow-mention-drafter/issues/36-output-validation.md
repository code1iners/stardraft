# 36: 출력 검증

**Spec:** [스펙](../spec.md) 6절 "출력"(형식 위반·근거 위치 검증)

**What to build:** 에이전트 출력이 스키마에는 맞지만 내용이 어긋나면 앱이 근거가 줄어드는 쪽으로 고쳐 보여 주고, 근거로 든 파일·줄이 실제로 있는지 확인해 없으면 "위치를 찾을 수 없음"으로 표시한다. 근거가 비밀 파일이면 결과를 버리고 "비밀 파일을 근거로 듦" 실패가 된다.

**Blocked by:** 35

**Status:** ready-for-agent

- [ ] 내용 불일치 표 여섯 행(없는 번호 제거, 참조 없는 근거는 끝에, 번호 다시 매김, 고친 요구로 덮어쓰기, 넘기지 않은 `repository`, 문장 0개)이 구현되고 고친 내용은 화면 없이 실행 기록에만 남는다.
- [ ] 근거 위치 검증 세 가지(저장소 안 경로인지 — `..`·절대 경로·심볼릭 링크 차단, 파일 존재, 줄 범위)에 실패한 근거는 "위치를 찾을 수 없음"으로 표시되고 "에디터에서 열기"가 꺼지며 번호는 유지된다.
- [ ] 근거 경로가 비밀 파일 패턴(기본 목록)에 맞으면 결과 전체를 버리고 실패("비밀 파일을 근거로 듦")로 두며 초안을 보여 주지 않는다. 대기열은 멈추지 않는다.
- [ ] 임시 디렉터리의 가짜 저장소와 가짜 출력으로 여섯 행과 세 가지 검증, 비밀 파일 경로가 테스트된다.
