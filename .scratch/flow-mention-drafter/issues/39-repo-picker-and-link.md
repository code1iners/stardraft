# 39: 저장소 선택 창과 연결 버튼

**Spec:** [스펙](../spec.md) 5절 "선택 결과의 재사용", "저장소 선택 창", 6절 재생성 표의 "다른 저장소로 다시 만들기"

**What to build:** "저장소를 골라 만들기"와 재생성 메뉴의 "다른 저장소로 다시 만들기"가 같은 저장소 선택 창을 연다. 여러 개를 고를 수 있고, 작업 폴더의 저장소와 다른 매핑에 쓰인 저장소가 후보로 보이며 "폴더 직접 고르기"도 있다. 저장소 영역의 "이 Flow 프로젝트에 연결"을 누르면 지금 구성이 매핑으로 저장된다.

**Blocked by:** 38

**Status:** ready-for-agent

- [ ] 선택 창은 처음에 지금 쓰는 저장소가 체크되어 있고, 고른 구성으로 초안 실행을 돌린다(처음 입력 + 바뀐 읽기 범위, 직전 결과 없음, 지시 초기화).
- [ ] 연결 버튼은 기존 매핑에 더하지 않고 덮어쓴다. 매핑이 있으면 문구가 "매핑을 이 구성으로 바꾸기"다. 선택 창 안에도 연결 버튼이 있다.
- [ ] 게시 때 "앞으로도 이 저장소로?" 대화상자는 없다.
- [ ] 가짜 설정 저장소로 덮어쓰기와 재생성 입력이 테스트된다.
