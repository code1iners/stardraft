# 41: 재생성

**Spec:** [스펙](../spec.md) 6절 "재생성 입력" 표, 4절 "처리 중인 묶음에 새 멘션이 올 때" 표의 준비됨 행, 8절 "행동과 버튼"

**What to build:** 바닥 줄의 재생성 메뉴에서 "다시 만들기", "지시를 덧붙여 다시 만들기"를 고르거나, 요구 제목 옆 망치 아이콘으로 요구를 고쳐 "이 요구로 재생성"할 수 있다. 편집한 초안이 있으면 버릴지 먼저 묻는다. 준비됨 묶음에 새 멘션이 오면 손대지 않았을 때는 자동으로 다시 만들고, 손댔으면 "새 멘션 1건"과 [다시 만들기]만 띄운다.

**Blocked by:** 38, 40

**Status:** ready-for-agent

- [ ] 재생성은 매번 새 실행이고 대기열 맨 앞에 들어간다. 입력 표: 다시 만들기(같은 구성), 지시 덧붙이기(처음 입력 + 직전 결과 + 지시 전부), 요구 고치기(처음 입력 + 고친 요구, 직전 결과 없음, 에이전트는 요구를 그대로 출력하고 요약만 새로). 요구를 고치면 지시를 초기화한다. 편집본은 넘기지 않는다.
- [ ] 자동으로 저장소를 고른 묶음에서 이 세 경로는 선택 실행을 다시 돌리지 않는다.
- [ ] 재생성하면 이전 초안과 비교 기준을 바로 지운다.
- [ ] 준비됨 묶음 합치기: 초안·요구·지시를 손대지 않았으면 합치고 자동 재생성, 손댔으면 합치기만. 받는 사람을 뺀 것은 손댐이 아니며, 새 멘션의 송신자는 전에 뺐더라도 다시 더한다. 실패 묶음에 새 멘션이 오면 합치고 자동 재시도.
- [ ] 가짜 실행기로 네 경로의 입력 구성과 합치기 표가 테스트된다.
