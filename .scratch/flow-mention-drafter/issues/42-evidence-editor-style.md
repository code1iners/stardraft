# 42: 근거 상호작용, 에디터에서 열기, 문체 검사

**Spec:** [스펙](../spec.md) 8절 "상세의 영역"의 근거, "행동과 버튼"의 에디터에서 열기, 6절 "초안 문체와 지침"의 문체 검사

**What to build:** 초안의 근거 번호를 누르면 근거 영역이 펼쳐지며 해당 근거가 강조된다. 근거의 위치 옆 "에디터에서 열기"를 처음 누르면 설치된 에디터 목록에서 고르고, 그 뒤로는 바로 그 줄이 열린다. 개발자 용어가 섞인 문장 옆에 "개발자 용어가 있을 수 있음"이 작게 보인다.

**Blocked by:** 40

**Status:** ready-for-agent

- [ ] 근거마다 자연어 설명, 작은 글씨의 "저장소 · 파일 · N번째 줄", "에디터에서 열기". 근거 없는 문장은 "근거 없음". 번호 클릭 시 펼침과 강조.
- [ ] 에디터 찾기(VS Code, Cursor, JetBrains IDE, Zed, Sublime Text)와 줄 단위 열기 방법(URL 스킴 또는 CLI)을 앱에 둔다. 처음 누를 때 고르게 하고 기억한다. 없으면 OS 기본 앱으로 파일만 연다. 설정 "일반"의 "직접 지정"은 `{file}`·`{line}` 자리가 있는 명령 한 줄이다.
- [ ] 문체 검사 대상: 백틱, 파일 확장자처럼 생긴 말, 경로 구분자, 점 표기 키, camelCase, snake_case, 대문자 상수. 멘션 원문과 스레드에 나온 단어는 뺀다. 초안 문장과 근거 설명 모두 검사하고 자동 재생성은 없다.
- [ ] 문체 검사 규칙과 예외가 테스트된다.
