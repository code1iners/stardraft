# 44: 게시 실패와 응답 없음

**Spec:** [스펙](../spec.md) 9절 "게시 실패", "올라갔는지 알 수 없을 때의 확인"

**What to build:** 게시가 실패하면 다른 묶음을 보고 있어도 토스트("게시하지 못했습니다: 김철수님 멘션")가 뜨고 트레이에 빨간 점이 생기며 실패 목록에 들어간다. 상세 머리에 쉬운 말 사유가 보이고 초안은 그대로 남아 [다시 게시]할 수 있다. Flow가 응답하지 않으면 실제로 올라갔는지 다시 조회해 정한다.

**Blocked by:** 43

**Status:** ready-for-agent

- [ ] 응답별 표: `403` 권한 없음, `404`/`412` 지워짐, `400`/`422` 받지 않음, `429`는 `Retry-After` 뒤 한 번 더 보내고 또 실패하면 한도 초과, `401`은 묶음 실패가 아니라 "키 확인 필요"와 준비됨 유지, 응답 없음/`5xx`는 확인 절차.
- [ ] 확인 절차: 그 자리(게시물 댓글 또는 스레드 대댓글)를 다시 조회해 이 PC가 기록한 적 없는 내 글 가운데 게시 본문과 똑같은 글을 찾는다. 찾으면 게시됨과 ID 기록, 못 찾으면 게시 실패("Flow가 응답하지 않았습니다"). 그대로 재시도하지 않는다.
- [ ] 게시 실패 상태: 실패 목록, 빨간 점, 토스트 한 번, 상세 머리 사유, 편집 가능, [다시 게시] [무시].
- [ ] 가짜 Flow API로 응답 코드 전부와 내용 일치 확인이 테스트된다.
