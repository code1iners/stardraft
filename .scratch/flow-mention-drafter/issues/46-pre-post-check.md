# 46: 게시를 누를 때의 확인

**Spec:** [스펙](../spec.md) 10절

**What to build:** [게시]를 누르는 순간 Flow를 한 번 더 조회해, 이미 내 답이 있거나 원문이 사라졌거나 화면에 없던 새 글·수정이 있으면 카운트다운 안에서 게시를 멈추고 토스트로 알린다. 이미 알림 줄에 떠 있던 변화뿐이면 그대로 게시한다. 조회가 실패하거나 늦으면 그대로 게시한다.

**Blocked by:** 45

**Status:** ready-for-agent

- [ ] 확인 결과 표 다섯 행이 구현된다. 멈춘 토스트 문구는 "게시하지 않았습니다: Flow에 이미 내 답이 있음 · 되돌리기", "게시하지 않았습니다: 새 글 1건 · 보기".
- [ ] 나를 멘션한 새 글도 멈춘다. 멈춘 뒤 다음 폴링의 알림은 준비됨 합치기 규칙으로 합쳐진다. 확인이 끝난 뒤 들어온 멘션만 "게시 중 행"(합치지 않음)을 적용한다.
- [ ] 카운트다운이 끝난 뒤 5초가 지나도 조회가 끝나지 않으면 게시한다.
- [ ] 조회한 내용을 "이 PC가 게시한 글이 답한 범위"로 저장한다.
- [ ] 가짜 Flow API와 가짜 시계로 다섯 행과 시간 경계가 테스트된다.
