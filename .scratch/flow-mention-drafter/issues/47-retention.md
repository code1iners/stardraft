# 47: 보관

**Spec:** [스펙](../spec.md) 12절(기록의 두 층, 처리됨 목록, 전체 기록, 최소 기록, 대기 중인 묶음)

**What to build:** 처리한 묶음은 7일 동안 처리됨 목록에 남고 그동안만 되돌릴 수 있다. 7일이 지나면 Flow 원문·초안·비교 기준·실행 기록이 지워지고 ID와 상태만 남는다. 대기 중인 묶음은 기한 없이 남는다.

**Blocked by:** 44, 45

**Status:** resolved

- [x] 전체 기록과 최소 기록의 구분이 저장소 스키마에 있다. 최소 기록은 묶음 자리, 멘션 위치, 마지막 상태와 시각, 이 PC가 게시한 글의 ID와 답한 멘션 위치뿐이다.
- [x] 처리한 때부터 7일(되돌렸다가 다시 처리하면 새로 셈), 설정 불가. 앱을 켤 때와 하루 한 번 정리한다. 게시됨도 같은 규칙.
- [x] 목록에서 빠질 때 전체 기록을 지우고 최소 기록만 남긴다. `secure_delete`가 켜져 있다. 최소 기록은 계정이 바뀔 때까지 남으며 같은 멘션 위치의 재알림을 막는다.
- [x] 시험 묶음은 보관 대상이 아니다(49). 마이그레이션 전 사본은 55에서 지운다.
- [x] 가짜 시계로 7일 경계, 되돌린 뒤 새로 세기, 삭제 뒤 최소 기록만 남는 것이 테스트된다.

## Comments

### 2026-10-22 구현과 검증 기록

**구조**

- 스키마(`state.db` 형식 14)
  - 전체 기록은 그대로 `mention_bundle`, `mention`, `bundle_answer`다.
  - 최소 기록은 새 표 `minimal_record`(묶음 자리, 마지막 상태, 처리한 시각, 게시한 글의 ID), `minimal_record_mention`(묶음에 있던 멘션 위치), `minimal_record_answered`(게시한 글이 답한 멘션 위치)에 둔다. 송신자 이름과 글 내용을 담을 열이 없다.
  - core 타입은 `MinimalRecord`이고, 게시한 글은 `posted: PostedAnswer | null`로 묶었다.
- 정리
  - `MentionBundles.archiveExpired`가 처리한 지 7일이 된 처리됨 묶음을 `StateStore.archiveBundles`로 최소 기록으로 바꾼다. 경계는 `now - processedAt >= 7일`이고, 되돌리면 `processedAt`이 지워졌다가 다시 처리할 때 새로 적힌다.
  - `archiveBundles`는 한 트랜잭션으로 지우고 넣은 뒤 WAL을 비운다(`secure_delete`는 열 때 이미 켜져 있다).
  - `BundleRetention`이 앱을 켤 때와 하루마다 정리한다. 맥에서 잠자기 동안 타이머가 멈출 수 있어 깨어날 때도 정리한다.
- 최소 기록의 쓰임
  - `hasMentionLocation`이 최소 기록의 멘션 위치도 보아 같은 위치의 재알림을 막는다.
  - 게시한 글이 답한 범위(`postedRanges`)와 `postedIds`에 최소 기록도 들어, 묶음이 지워진 뒤에도 카운트다운 중에 온 멘션의 묶음이 "이미 답함"으로 숨지 않고 응답 없는 게시의 내용 일치 확인이 옛 글을 고르지 않는다.
- 7일이 지났지만 아직 정리되지 않은 묶음을 되돌리면, 되돌리지 않고 그때 정리해 목록에서 뺀다.

**검증**

- `pnpm typecheck`, `pnpm lint`, `pnpm test` 통과.
- 가짜 시계 테스트(`retention.test.ts`): 7일 직전과 7일째, 하루 정리, 되돌린 뒤 새로 세기, 대기 중인 묶음은 남음, 이미 답함과 게시됨도 같은 규칙, 깨어날 때 정리, 최소 기록만 남음, 재알림 막기, 게시한 글이 답한 범위 유지.
- SQLite 테스트(`state-database.test.ts`): 최소 기록 저장과 다시 열기, 지운 원문·송신자 이름·편집본·지시가 `state.db`와 WAL에 남지 않음, 계정을 바꾸면 최소 기록도 지움, 형식 13에서 올리기.

**범위 밖**

- 시험 묶음은 아직 없다. 49가 시험 묶음을 끝낼 때 지우므로 처리됨에 남지 않고, 이 정리의 대상이 아니다.
- 마이그레이션 전 사본 삭제는 55가 맡는다.

**남겨 둔 점**

- 정리는 하루에 한 번이라, 7일이 지난 뒤 다음 정리까지 최대 하루 동안 목록에 [되돌리기]가 보일 수 있다. 누르면 되돌리지 않고 항목이 목록에서 빠진다.
- 처리한 시각 없이 처리됨이 된 묶음은 지금 생기는 경로가 없다. 있으면 영영 남지 않도록 만든 시각으로 센다.
- `GLOSSARY.md`는 바꾸지 않았다. "최소 기록", "처리됨 목록"은 스펙 용어를 그대로 썼다.
