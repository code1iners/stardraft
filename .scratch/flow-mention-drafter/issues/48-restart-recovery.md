# 48: 다시 켜기

**Spec:** [스펙](../spec.md) 12절 "끌 때", "다시 켤 때", 8절 상세 머리 문구

**What to build:** 앱을 껐다 켜면 생성 중이던 묶음이 원래 순서로 대기열에 돌아와 처음부터 실행된다. 카운트다운 중에 꺼졌으면 게시하지 않고 준비됨으로 돌아오며 "앱이 꺼져서 게시하지 않았습니다"가 보인다. 게시 응답을 못 받고 꺼졌으면 "게시 결과 확인 중"으로 두고 첫 조회 뒤 게시됨 또는 게시 실패로 정한다. 편집 중이던 초안은 그대로 보인다.

**Blocked by:** 37, 44

**Status:** ready-for-agent

- [ ] 끌 때 에이전트 프로세스 트리를 종료하고 확인 창은 없다. 게시 요청 중이면 응답을 최대 5초 기다린다. 편집기 내용을 저장한다.
- [ ] 끊긴 실행은 "앱 종료로 중단"으로 기록하고 자동 재시도 1회에 세지 않으며, 다시 켜면 맨 앞에서 처음부터 돈다. 생성 직전 이미 답함 확인을 거친다.
- [ ] 카운트다운 중 종료 → 준비됨, 조회한 내용 버림, 안내 한 줄.
- [ ] 보내기 전 기록만 있고 결과가 없는 묶음 → 게시 중("게시 결과 확인 중", 게시 버튼 막음) → 44의 내용 일치 확인으로 게시됨 또는 게시 실패("앱이 꺼져서 게시하지 못했습니다"). 조회 실패면 다음 폴링에서 다시.
- [ ] 진행 중이던 시험 묶음은 지운다(49와 맞춤).
- [ ] 가짜 저장소 상태를 넣고 시작 절차를 돌려 네 경우가 테스트된다.
