# 49: 최근 멘션으로 시험

**Spec:** [스펙](../spec.md) 13절 "최근 멘션으로 시험", 7절 시험 묶음

**What to build:** 감지 중 묶음이 없을 때의 빈 작은 창과 설정 "초안" 칸의 [최근 멘션으로 시험]을 누르면 최근 멘션 10건이 보이고, 하나를 고르면 실제와 똑같이 초안이 만들어진다. 시험 묶음에는 "시험" 표시와 "Flow에는 아무것도 올라가지 않습니다"가 붙고 [게시] 대신 [시험 끝내기]가 있다. 끝내면 묶음이 지워진다.

**Blocked by:** 39, 41

**Status:** ready-for-agent

- [ ] 감지를 시작한 뒤에만 쓸 수 있다. 멘션 고르기 목록은 판정 규칙을 통과한 최근 10건(72시간 제한 없음)을 송신자·Flow 프로젝트·첫 줄·시각으로 보이고, 이미 답한 멘션에 "답함"을 붙이되 고를 수 있다. 자동 선택은 없다.
- [ ] 실제 에이전트·저장소로 선택 실행과 초안 실행이 대기열 맨 앞에서 돌고, 트레이 숫자와 "[시험] …" OS 알림이 평소처럼 나온다. 재생성, 지시, 저장소 바꾸기, 근거 보기, 연결이 모두 된다.
- [ ] 직접 답 확인과 변화 감시는 건너뛴다. 코드와 무관하면 저장소 확인 필요로 끝난다. 한 번에 하나만.
- [ ] 끝내기나 무시를 누르면 묶음과 실행 기록을 지우고 처리됨·기준점에 남기지 않는다.
- [ ] 가짜 포트로 목록 구성, 시험 묶음의 차이점, 삭제가 테스트된다.
