# 50: 초안·일반 설정

**Spec:** [스펙](../spec.md) 6절 "비밀 파일 패턴", "초안 문체와 지침"의 추가 지침, "실행 제어"의 설정 변경 반영, 13절 "설정 창"

**What to build:** 설정 "초안" 칸에서 모든 초안에 적용되는 추가 지침을 적고, 읽기 전용 기본 목록 아래에 비밀 파일 패턴을 추가할 수 있다. 패턴을 추가하면 실행 중인 실행이 새 패턴으로 다시 돌고, 게시하지 않은 초안의 근거가 다시 검사된다. "일반" 칸에 로그인 시 자동 시작 토글과 알림 시험이 있다.

**Blocked by:** 36, 37

**Status:** ready-for-agent

- [ ] 추가 지침은 여러 줄 입력이며 칸을 벗어날 때 저장하고 "저장됨"을 표시한다. 기본 지침 뒤에 붙고 다음 실행부터 적용되며 이미 만든 초안은 다시 만들지 않는다.
- [ ] 비밀 파일 패턴은 추가만 할 수 있고 앱 전체에 적용된다. 기본 패턴 삭제와 저장소별 패턴은 없다.
- [ ] 패턴 추가 시 실행 중인 실행을 취소해 대기열 맨 앞에 다시 넣고, 게시하지 않은 초안의 근거 경로를 다시 검사해 걸리면 결과를 버리고 실패("비밀 파일을 근거로 듦")로 둔다.
- [ ] "일반" 칸: 로그인 시 자동 시작 토글, 알림 시험 버튼, 에디터 직접 지정(42), 폴더 열기와 버전(24).
- [ ] 가짜 실행기와 임시 저장소로 패턴 반영 두 경우가 테스트된다.
