# 54: 앱 내 업데이트: 확인·다운로드·서명 검증

**Spec:** [스펙](../spec.md) 14절(출처, 확인 시점, 진위 확인, 스스로 바꿀 수 없는 위치)

**What to build:** 앱이 켜지고 1분 뒤와 4시간마다 공개 Release에서 새 버전을 확인해 묻지 않고 받는다. 받은 파일의 서명 문장을 앱에 든 공개 키로 검증해 통과할 때만 "설치 준비됨"이 된다. 틀리면 파일을 지우고 "업데이트 파일의 서명이 맞지 않아 설치하지 않았습니다. 지금 버전을 계속 씁니다."를 보인다. 앱이 스스로 바꿀 수 없는 위치면 받지 않고 [사이트에서 받기]만 보인다.

**Blocked by:** 26, 53

**Status:** ready-for-agent

- [ ] electron-updater `github` provider, `autoInstallOnAppQuit = false`, 차등 다운로드 끔. 잠자기에서 깨어났을 때 마지막 확인이 4시간보다 오래됐으면 바로 확인. 설정 "일반"의 [지금 확인]. 끄는 설정은 없고 개발 모드는 업데이트를 끈다.
- [ ] `update-downloaded`에서 네 조건(직접 계산한 sha512 일치, 서명 목록 중 하나가 공개 키 목록 중 하나로 검증, 서명 문장의 버전이 yml과 같고 지금보다 높음, 파일 이름 일치)을 모두 확인한다. 필드 없음·형식 오류도 실패.
- [ ] 실패 시 파일 삭제, 같은 버전 자동 재다운로드 금지(더 새 버전은 받음), [다시 시도]로 재다운로드, 수동 설치 권유 없음.
- [ ] 위치 확인(번들·부모 폴더 쓰기 가능, 읽기 전용 볼륨·App Translocation)을 확인할 때마다 하고, 불가하면 사유 문구("응용 프로그램 폴더로 옮긴 뒤 다시 여세요" / "이 계정은 Stardraft를 바꿀 권한이 없습니다")와 [사이트에서 받기]만. 관리자 인증 창은 띄우지 않는다.
- [ ] 업데이트 상태(최신·확인 중·받는 중·설치 준비됨·서명 검증 실패·확인 실패·바꿀 수 없는 위치)가 core 상태 기계에 있고 설정 "일반"에 상태 문구가 보인다(메뉴·띠는 55).
- [ ] 가짜 피드와 가짜 파일로 네 조건의 성공과 각각의 실패(sha512 변조, 서명 변조, 버전 불일치, 이름 불일치)가 테스트된다.
