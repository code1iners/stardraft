# 57: 다운로드 사이트: 설치 안내 예시 화면

**Spec:** [스펙](../spec.md) 16절 "설치 안내", "예시 화면과 스크린숏", "모션"

**What to build:** 설치 안내 섹션에 OS 탭(기본값은 감지 결과)과 macOS 5단계·Windows 4단계가 있다. 단계마다 제목, "이 문구가 보이면", 지시(버튼 이름 굵게), 눌러 볼 수 있는 HTML 예시 화면, 완료 기준, "여기서 막히면" 펼침이 있다. 예시 화면이 보이는 위치까지 스크롤하면 커서가 누를 곳으로 움직이고 강조 테두리가 깜빡인다. 막히는 네 곳에는 실제 스크린숏 자리를 두고 "예시"로 바꿀 수 있다.

**Blocked by:** 56

**Status:** ready-for-agent

- [ ] 단계 내용과 "여기서 막히면" 열 항목(손상됨, 휴지통으로 이동, Intel Mac, 그래도 열기 안 보임, 노치, 알림 허용 놓침, 실행 버튼 없음, 스마트 앱 컨트롤 차단, 실행 중입니다 창, 트레이 숨김 영역)이 스펙 문구대로다. macOS 1단계에 `~/Applications` 한 줄이 있다. 스마트 앱 컨트롤 단계는 상태별 표다.
- [ ] 예시 화면: 누를 곳을 누르면 다음 상태로 넘어가고, 잘못된 버튼은 경고를 띄우며 "처음부터"가 있다. 위에 노란 띠 "예시 화면 · 눌러 볼 수 있지만 실제 창이 아닙니다", 빗금 배경, 항상 단계 안의 틀 속.
- [ ] 막히는 네 곳은 실제 스크린숏이 기본이고 "예시"로 전환된다. 스크린숏 파일 자리는 비워 두고 59·60에서 채운다. Keychain 예시 화면은 앱의 다시 시작 확인 화면과 같은 것을 쓴다.
- [ ] 커서 이동·강조·장면 전환은 `prefers-reduced-motion`이면 모두 멈추고 마지막 모습만 보이며 커서는 누를 곳에 바로 놓인다(CSS와 JS 모두).
- [ ] 다른 OS용 받기를 누르면 탭도 그 OS로 바뀐다. 넣지 않는 것(`xattr`, 연락 절차, SAC 끄기 안내, 우클릭 열기)이 없다.
- [ ] 예시 화면의 상태 전환과 reduced-motion 분기가 테스트된다.
