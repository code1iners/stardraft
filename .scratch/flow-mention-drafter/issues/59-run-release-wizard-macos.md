# 59: 출시 마법사 실행 (macOS)

**Spec:** [스펙](../spec.md) 테스트 결정 "실기 점검 목록", 추가 참고 "미결 사항"

**What to build:** 저장소 주인이 자기 Mac에서 58의 출시 마법사를 처음부터 끝까지 돌린다. 끝나면 `stardraft`가 GitHub에 공개되어 있고, `v0.1.0`이 공개 Release로 올라가 있으며, 사이트가 `stardraft.squadify.app`에서 다운로드를 내주고, 앱이 내 Mac에서 멘션을 감지해 초안을 만들며, macOS 실기 점검 결과와 스크린숏이 저장소에 반영되어 있다.

**Blocked by:** 58

**Status:** ready-for-human

- [ ] 마법사 16개 스테이지를 모두 통과했거나, 통과하지 못한 스테이지와 이유가 기록되어 있다.
- [ ] 미서명 macOS 점검 목록 다섯 항목의 결과가 기록되어 있다.
- [ ] 스크린숏 두 곳이 사이트에 들어가고 재현 화면 문구가 실제 화면과 맞다.
- [ ] 앱 내 업데이트 실측(두 번째 버전)과 오류 경로 두 경우의 결과가 기록되어 있다.
- [ ] 동료와 한 확인 두 가지의 결과가 스펙(받는 사람 줄 유지 여부, 채팅 멘션 범위 밖 항목)에 반영되어 있다.
- [ ] 실기에서 드러난 문제는 새 티켓으로 만든다.
