# 60: Windows 점검 마법사 실행

**Spec:** [스펙](../spec.md) 테스트 결정 "팀 배포 전 Windows 점검 목록"

**What to build:** 팀원에게 배포하기 전에 Windows PC에서 58의 Windows 점검 마법사를 돌린다. 끝나면 13개 점검 항목의 결과와 Windows 스크린숏 두 곳이 저장소에 반영되어 있고, Windows에서 막히는 문제가 티켓으로 남아 있다.

**Blocked by:** 59

**Status:** ready-for-human

- [ ] 설치 경로(SmartScreen), 알림 표시와 클릭, 자동 시작, `.cmd` 래퍼 CLI 실행과 프로세스 트리 종료, 한글 사용자 이름 경로, `safeStorage`, better-sqlite3 로드, 트레이 숨김 영역과 첫 실행 작은 창, 조용한 설치와 재실행, MOTW와 SmartScreen, 설치 도중 강제 종료, 업데이트 뒤 유지 항목, 설치 실패 띠의 결과가 기록되어 있다.
- [ ] 스크린숏 두 곳(PC 보호 화면, 스마트 앱 컨트롤 설정)이 사이트에 들어가고, 메뉴 이름("앱 & 브라우저 컨트롤"/"앱 및 브라우저 컨트롤")과 상태 이름이 사이트 문구에 반영되어 있다.
- [ ] 실기에서 드러난 문제는 새 티켓으로 만든다.
