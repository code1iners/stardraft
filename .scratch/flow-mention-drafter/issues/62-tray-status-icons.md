### 최종 수용 범위와 판정

- Windows 실기 확인은 사용자 답변 **“windows 는 완료 조건에서 제외.”**에 따라 필수 조건에서 제외했다. Windows 구현은 유지하며 실기 통과로 간주하지 않는다.

- 자동 캡처는 현재 명령 실행 환경의 화면 기록 접근 제한으로 실패했다. 실제 화면 수용 근거는 사용자의 직접 확인이다.

추가 실기는 필요할 때 선택 검증으로 수행할 수 있으며 이 티켓의 종료를 막지 않는다. `pnpm --filter @stardraft/desktop preview:tray`는 임시 사용자 데이터로 검증 앱을 실행한다. Windows라면 시스템 테마·배율, macOS라면 화면 모드·동작 줄이기·실제 절전/복귀를 추가로 살펴볼 수 있다. 운영 계정 데이터 수정·실제 게시·푸시·릴리스는 필요하지 않다.
