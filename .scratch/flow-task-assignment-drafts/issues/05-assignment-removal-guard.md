# 05: 담당 해제 시 생성 중단과 게시 차단

Status: ready-for-agent
Blocked by: 02 (생성 시 배정된 업무의 최초 초안과 게시)

**What to build:** 담당 업무 초안을 만드는 중 내가 담당자에서 제외되면 생성을 중단한다. 이미 만들어진 초안은 제외 사유와 함께 남기고 게시를 막아, 더 이상 맡지 않은 업무에 답변하지 않도록 한다.

스펙: [담당 업무 최초 초안](../spec.md)
연결 요구: Q7. 사용자 이야기 22, 23, 27.

- [ ] 생성 직전과 생성 중 확인된 담당 해제로 불필요한 실행을 진행하지 않는다. 이미 실행 중이면 중단하며 뒤늦게 도착한 실행 결과가 게시 가능한 초안으로 되살아나지 않는다.
- [ ] 검토 중 담당 해제를 확인하면 기존 초안과 사용자 편집 내용을 보존하고, 화면에 제외 사유와 게시 불가 상태를 표시한다.
- [ ] 게시 직전 담당 상태를 다시 확인하여 확인된 해제 상태에서는 게시 요청을 보내지 않는다. 실제 확인과 게시 사이에 가능한 외부 변경 경계를 기록하고 완전한 원자성을 주장하지 않는다.
- [ ] 조회 실패를 담당 해제로 기록하지 않는다. 확인 실패 시 기존 게시 전 확인의 실패 처리를 따르며, 실패를 정상 확인으로 취급해 게시하지 않는다.
- [ ] 여러 담당자 중 다른 사람이 빠진 경우와 내가 빠진 경우를 구분한다. 현재 내 담당 여부를 기준으로 처리한다.
- [ ] 기존 직접 멘션만으로 생성된 초안의 유효성 판정을 담당 업무 해제 규칙으로 대체하지 않는다. 담당 업무 초안의 해제 사유와 생성 상태를 구분하여 저장한다.
- [ ] 기존 변화 감시·게시 전 확인과 통합 테스트에서 생성 중 해제, 준비 후 해제, 게시 직전 해제, 조회 실패, 취소 후 늦은 실행 결과를 검증한다.
- [ ] 마지막 변경 이후 정적 검사·관련 자동 테스트를 실행하고, 실제 데스크톱에서 초안 보존·제외 사유·게시 차단을 확인한다. 멘션 통합 사례와의 결합 검증은 06에서 수행한다.
