# 03: 시험 기능 제거 (contract)

**What to build:** 앱에서 "시험"이 사라진다. 사용자는 시험 묶음, [시험 끝내기], "[시험] …" 알림, "시험" 태그를 더 이상 보지 않고, 같은 기능이 두 이름으로 남지 않는다. 스펙: `../spec.md`의 "시험 기능 폐지".

- 시험 묶음 표시, 시험 삭제 규칙(끝내거나 무시하면 기록째 지움), 대기열의 시험 우선순위, 시험 전용 알림, 시험 진행 상태와 IPC 명령, 시험 시작·고르기 코드, 시험 전용 문구와 스타일을 지운다.
- 업데이트 후 첫 실행에서 남아 있는 시험 묶음을 지운다(기존 "진행 중이던 시험 묶음 삭제" 규칙을 이어 쓴다). 저장 스키마에 시험 표시 열이 있으면 마이그레이션으로 정리한다.
- 이 저장소의 다른 스펙과 티켓에서 시험을 참조하는 곳은 08에서 문서로 정리한다. 이 티켓은 코드와 테스트만 다룬다.

**Blocked by:** 02 (최근 멘션 확인 화면 연결)

**Status:** ready-for-agent

- [ ] 코드와 사용자에게 보이는 문구에서 "시험"(알림 시험 제외), 시험 묶음, [시험 끝내기]가 사라졌다. 남은 "시험" 문자열은 설정 "일반"의 "알림 시험"뿐이다(검색으로 확인).
- [ ] 시험 전용 테스트는 삭제하거나 새 동작 검증으로 바꾸고, 나머지 자동 테스트는 모두 통과한다.
- [ ] 시험 묶음이 남은 DB로 시작해도 정리되고 일반 묶음은 영향을 받지 않는다(실제 DB·마이그레이션 테스트).
- [ ] 수동 요청 묶음의 생성·검토·게시 흐름이 이 티켓 뒤에도 그대로 동작한다.
- [ ] 마지막 변경 이후의 전체 정적 검사와 자동 테스트가 통과한다.
