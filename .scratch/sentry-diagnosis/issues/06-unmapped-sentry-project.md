## Question

저장소 매핑이 없는 Sentry 프로젝트에서 오류 이슈가 왔을 때 어떻게 할지 정한다.

- 선택지: 건너뛰고 매핑을 요청하는 알림만 띄우기, 작업 폴더에서 **자동 선택**(Flow와 같은 방식), 스택트레이스 파일 경로·release로 저장소를 추정하기.
- 자동 선택이나 추정 결과를 사용자가 저장해 저장소 매핑으로 굳히는 흐름을 Flow와 같게 둘지.
- 매핑된 저장소가 여럿일 때 스택트레이스로 범위를 좁힐지.
