## Comments

### 2026-11-26 실측 결과와 멈춘 까닭

결과는 [재현 경계와 CLI 실측](../research/reproduction-boundary-live-check.md)에 있다. 체크 항목의 실측은 모두 했다. Codex는 모델 호출 없이 되는 부분(`codex sandbox`, `codex mcp list`, MCP 서버 시작)만 확인했고, 모델 실행이 필요한 것은 "확인 못 함(미구독)"으로 적었다(이 계정의 Codex는 `You’ve hit your usage limit ... try again at Nov 29th, 2026 2:05 PM.`으로 끝남). 앱 코드는 바꾸지 않았다.

**스펙 7절 "CLI별 구현" 표와 다른 것 하나 → `blocked`**

- 표의 Claude Code "강제 종료" 칸은 "프로세스 그룹 종료로 MCP까지 끝난다"이다.
- 실측: stdio MCP 서버는 `claude`와 같은 그룹이라 그룹 `SIGKILL`로 끝났다. 그런데 **Bash 명령은 포그라운드·백그라운드 모두 명령마다 새 프로세스 그룹(`zsh -c ...`)을 만들어서, CLI 그룹 `SIGKILL` 뒤에도 살아남았다**(`sleep 600`, Python 프로세스). dev 서버를 띄운 재현이 끊기면 서버가 남는다는 뜻이다.
- Codex 칸의 순서(CLI 그룹을 끝내기 직전에 자손을 모아 그 그룹들을 먼저 끝낸다)를 Claude Code에 그대로 쓰자 MCP 서버와 두 셸 명령이 모두 끝났다.

**사용자가 정해 줄 것**
1. (추천) 스펙 7절 표의 Claude Code "강제 종료" 칸을 Codex와 같은 순서("CLI 그룹을 끝내기 직전에 자손을 모아 그 프로세스 그룹들을 먼저 끝낸다")로 바꾼다. 실측으로 통함을 확인했다. 그러면 이 티켓을 `resolved`로 닫는다.
2. 또는 Claude Code는 그룹 종료만 두고, 셸 명령이 남을 수 있음을 "알려진 한계"에 적는다.

**스펙 방향은 그대로이고 구현에서 챙길 것**(조사 문서 "구현 메모")
- APFS 복제: `.git` 뺀 6.1GB·약 26만 파일에서 맨 위 항목마다 `clonefile(2)`는 약 5초, `cp -c -R`은 55~99초였다. 삭제는 약 24초.
- 사본에 linked worktree의 `.git` 포인터 파일(원본 `.git`을 가리킴)과 원본 `.env`를 가리키는 절대 링크가 남는다. Claude 확정 묶음에서는 `.git/**` deny가 포인터 읽기를 막고 사본 밖 쓰기가 막혀 경계가 깨지지 않았다. Codex는 `"**/.git"="deny"`를 더해야 막힌다.
- Claude: 지금 deny 형식(`Read(//**/<패턴>)`)을 샌드박스에 그대로 합치면 `/etc/ssl/cert.pem`과 `~/.npmrc`가 막혀 curl·Python HTTPS가 깨진다. 사본 경로로 좁힌 형식 + `.env` 계열은 샌드박스 `denyRead` 루트 전체 + 사본 `allowRead`로 풀면 부작용 없이 막고 열린다. `autoAllowBashIfSandboxed` 기본값이 `false`라 `Bash`·`Edit`·`Write` 허용 규칙이 필요하다. 네트워크는 `allowedDomains: ["*"]`로 열리지만 Node `fetch`는 `NODE_USE_ENV_PROXY=1`이 있어야 샌드박스 프록시를 탄다.
- Codex 프로필: 글롭 경로는 `deny`만 되어 사본 `.env`만 다시 열 수 없다. 사본을 홈 밖에 두고 `~/**/.env` 계열을 막는 식으로 같은 경계가 됐다.
- Claude 실행 중 전달은 앱 플래그 묶음·MCP·지침 파일·sonnet과 함께 동작했다. Claude 5개 동시 실행 두 번 모두 충돌 없음 → 병렬 작업 수 상한 5를 낮출 근거 없음.
- 시뮬레이터·에뮬레이터: 켜진 목록 차집합으로 새로 켜진 것만 골라 `xcrun simctl shutdown <UDID>`(12초), `adb -s emulator-<n> emu kill`(3초)로 끈다. 사용자 시뮬레이터·실기기·adb 서버는 남았다.
- `codex mcp list --json` 출력에 MCP 헤더·환경 값이 평문으로 들어 있다. 앱은 이 출력을 로그에 남기지 말아야 한다.

**남긴 것**: 시험은 임시 폴더의 가짜 저장소와 사본으로 했고 끝난 뒤 지웠다. 켠 시뮬레이터·에뮬레이터는 모두 껐다. 재현 저장소 원본은 읽기만 했다(`git status` 변경 없음).
