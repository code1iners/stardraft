# 27: 확인 창을 화면 가운데 모달로

**Spec:** [스펙](../spec.md) 14절 "모달"

**What to build:** 계정 바꾸기, 저장소 선택, 에디터 선택 창이 창 위쪽에 붙는 시트가 아니라 화면 가운데 모달로 뜬다. 동작과 문구는 그대로다.

**Blocked by:** 24

**Status:** resolved

- [x] 세 확인 창이 가운데 모달(모서리 10px, 배경을 어둡게 덮음)로 그려진다.
- [x] 처음 초점, Esc로 취소, 버튼 순서는 지금과 같다.
- [x] 시트 전용 스타일과 이름이 남아 있지 않다.
- [x] 세 창의 렌더링 테스트가 모달 모양을 검사한다.
- [x] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.

## Comments

- 세 창과 함께 같은 시트 스타일을 쓰던 최근 멘션 확인 창도 모달로 바꾸고 이름을 `*Modal`, `.modal*`로 통일했다(시트 전용 스타일 제거). 스냅숏 필드 `sheet`는 데이터 이름이라 그대로 뒀다.
- `pnpm lint`, `pnpm typecheck` 통과. `pnpm test`는 데스크톱 1344건 통과, `apps/site`의 `index-page.test.ts` 한 건("처음 열면 뜨는 창에서 완료 누르기")이 이 변경 이전부터 실패한다(변경을 치운 상태에서도 재현).
