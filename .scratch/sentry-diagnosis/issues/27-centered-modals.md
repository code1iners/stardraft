# 27: 확인 창을 화면 가운데 모달로

**Spec:** [스펙](../spec.md) 14절 "모달"

**What to build:** 계정 바꾸기, 저장소 선택, 에디터 선택 창이 창 위쪽에 붙는 시트가 아니라 화면 가운데 모달로 뜬다. 동작과 문구는 그대로다.

**Blocked by:** 24

**Status:** ready-for-agent

- [ ] 세 확인 창이 가운데 모달(모서리 10px, 배경을 어둡게 덮음)로 그려진다.
- [ ] 처음 초점, Esc로 취소, 버튼 순서는 지금과 같다.
- [ ] 시트 전용 스타일과 이름이 남아 있지 않다.
- [ ] 세 창의 렌더링 테스트가 모달 모양을 검사한다.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.
