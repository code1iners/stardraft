# 31: 작업 폴더·자동 선택 걷어내기와 필수 설정 하나

**Spec:** [스펙](../spec.md) 15절 "걷어 내는 범위", "프로바이더는 모두 선택", 14절 "온보딩"

**What to build:** 작업 폴더와 자동 선택이 화면과 코드에서 사라진다. 필수 설정은 에이전트 연결 하나가 되어, Flow 키 없이도 감지를 시작할 수 있다.

**Blocked by:** 30

**Status:** ready-for-agent

- [ ] 자동 선택 모듈, 선택 실행 종류(새 실행에서), 선택 실행 시간 제한과 턴 상한, "저장소 고르는 중" 단계, 자동 선택 안내 문구가 없다. 과거 실행 기록의 선택 실행은 "저장소 선택(폐지됨)"으로 읽힌다.
- [ ] 작업 폴더 모듈과 스캔, 폴더 제안, 관련 IPC와 변경 이벤트, 설정 화면 항목이 없다. 네트워크·WSL 폴더 거부 규칙은 남아 매핑 폴더 선택에 쓰인다.
- [ ] 설정 파일의 옛 작업 폴더 키는 읽지 않고 파일에 남는다. 설정 스키마 버전은 그대로다.
- [ ] 필수 설정 항목이 에이전트 연결 하나다. 작은 창 체크리스트가 "필수"와 "감지할 대상 · 선택"(Flow 계정) 두 묶음이고, 선택 항목은 `✓` 또는 "연결 안 함"이다(Sentry 줄은 34번이 더한다).
- [ ] 필수를 마쳤는데 연결한 프로바이더가 없으면 막지 않고 안내 문구를 보인다. 설정 창 맨 위 띠는 진행 막대 없이 "필수 설정: 에이전트 연결"과 [에이전트 설정]이다.
- [ ] Flow 감지는 Flow를 연결했고 감지를 시작했을 때만 돈다. Flow 키가 없어도 앱의 다른 부분이 문제 없이 뜬다.
- [ ] 저장소 칸에서 작업 폴더 항목이 빠지고, 매핑이 없어 기다리는 Flow 프로젝트가 맨 위에 "저장소 매핑 없음 · n건 대기"와 [폴더 고르기…]로 보인다.
- [ ] 작업 폴더를 가리키는 문구가 화면과 알림에 남아 있지 않다.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.
