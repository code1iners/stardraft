# 39: 내보내기

**Spec:** [스펙](../spec.md) 11절 "내보내기", "완료"의 확인, 12절 바닥 줄, 14절 "보고서를 내보낼 폴더"

**What to build:** 검토 대기인 진단 보고서를 마크다운 파일로 **내보낸다**. 내보내지 않고 완료하려 하면 확인을 받는다.

**Blocked by:** 38

**Status:** ready-for-agent

- [ ] 검토 대기의 주 버튼이 [내보내기]다. 누르면 설정의 폴더에 `YYYY-MM-DD-<Sentry 프로젝트 이름>-<짧은 ID>.md`가 만들어지고(날짜는 감지한 날), 같은 이름이 있으면 `-2`, `-3`이 붙는다.
- [ ] 파일의 순서가 제목 → 요약 → 재현 → 원인과 확신도 → 개선 방향 → 근거 → 남은 의문 → 오류 이슈 정보 → 실행 정보다. 재현이 실패·불가일 때만 "시도한 것"이 들어간다.
- [ ] 첨부가 있으면 보고서와 같은 이름의 폴더에 복사되고 상대 링크로 걸린다.
- [ ] 내보내면 토스트 "내보냈습니다: `<파일 이름>`"과 [폴더 열기]가 뜨고 상태는 바뀌지 않는다. 몇 번이든 할 수 있다.
- [ ] 지금 보이는 보고서를 내보낸 적이 없으면 [완료]가 바닥 줄 확인("내보내지 않았습니다. 완료하면 이 보고서가 사라집니다.", [취소] · [내보내기] · [완료])을 거친다. 내보낸 적이 있으면 바로 완료된다.
- [ ] 완료 최소 기록에 마지막으로 내보낸 파일 경로가 남고, `완료함`의 `기록`에 보인다.
- [ ] Sentry 칸 맨 아래에 "보고서를 내보낼 폴더"가 있고(기본값은 사용자 문서 폴더 아래 `Stardraft/Reports/Sentry/`), [바꾸기…]와 [폴더 열기]가 된다. 토큰이 없어도 보인다.
- [ ] 파일 이름, 번호 붙이기, 첨부 폴더, 확인의 기준이 임시 디렉터리에서 테스트된다.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.
