# 41: 재현 허용과 재현 도구 권한 설정

**Spec:** [스펙](../spec.md) 14절 "저장소 칸"의 재현 항목, "에이전트 칸 · 재현", 7절 "MCP 싣기"의 재현 도구 권한과 목록 읽기, 1절 "OS"

**What to build:** macOS에서 저장소마다 **재현 허용**을 켜고 **재현용 환경 파일**을 정하며, 에이전트 칸의 `재현` 탭에서 **재현 도구 권한**을 고른다. 이 티켓은 설정만 다루고, 실제 실행은 42·43번이 한다.

**Blocked by:** 35

**Status:** resolved

- [x] 저장소 칸의 탭 아래 "재현" 항목에 매핑된 저장소마다 재현 허용 체크 상자가 있다. 켜면 환경 파일과 [바꾸기…]/[파일 고르기…]가 보이고, 지정하지 않았으면 "지정 안 함 · 원본 .env 사용"이 빨간 글씨로 보인다.
- [x] 재현을 켜는 순간 확인 모달이 뜬다. 허용되는 일(셸, 네트워크, MCP), 환경 파일 고르기, 원본 `.env` 경고, "운영 키를 넣지 마세요", "MCP 인증 값도 에이전트에게 노출될 수 있다"가 들어간다. 취소하면 켜지지 않는다.
- [x] 에이전트 칸에 `재현` 탭이 있고(탭 순서 `연결` · `재현` · `병렬 작업`), 라디오 `자동`(기본)과 `직접 선택`이 있다.
- [x] MCP 서버 목록이 보인다. Claude Code는 설정 파일을 직접 읽고 Codex는 서버를 띄우지 않는 목록 명령으로 읽는다. 줄마다 이름, 종류, 출처 CLI, 앱이 뺀 위험 도구가 보이고 외부로 보낼 수 있는 서버에 "외부로 보냄" 꼬리표가 붙는다.
- [x] 앱이 서버 정의의 값(환경 변수, 헤더)을 화면, 설정 파일, 로그에 남기지 않는다. 테스트가 이를 검사한다.
- [x] `직접 선택`에서 줄마다 체크 상자가 있고, 설정에는 에이전트별로 켠 서버 이름만 저장된다. 새로 등록된 서버는 꺼진 채로 나타난다. 저장소의 프로젝트 정의 파일에 있는 서버는 목록에 없다.
- [x] `자동`에서는 외부로 보내는 MCP도 실린다는 경고가, MCP가 없으면 "셸로만 재현, 조작이 필요하면 불가(도구 없음)"가, 플러그인 MCP와 커넥터는 실리지 않는다는 안내가 보인다.
- [x] Windows에서는 재현 항목과 `재현` 탭이 보이지 않는다.
- [x] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.
