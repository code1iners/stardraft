# 44: 시간 연장 묻기와 마무리

**Spec:** [스펙](../spec.md) 7절 "시간 상한과 연장", 9절 "진단 실패"의 [재현 없이 다시 시도], 12절 바닥 줄, 13절 연장 묻기

**What to build:** 재현하는 진단이 상한 5분 전에 계속할지 묻는다. 계속하면 10분씩 늘고, 멈추거나 답이 없으면 Claude Code는 그때까지 알아낸 것으로 보고서를 마무리한다. 시간 초과로 실패한 진단은 재현 없이 다시 돌릴 수 있다.

**Blocked by:** 38, 42

**Status:** ready-for-agent

- [ ] 실행기 포트에 "실행 중 전달"이 선택 능력으로 있고, Claude Code 실행기가 스트림 입력으로 갖춘다. Codex 실행기는 갖추지 않는다. 대기열은 능력이 있는지만 본다.
- [ ] 재현하는 진단만 상한 5분 전에 묻는다. 읽기 전용 진단과 Flow 초안은 묻지 않고 상한에서 끊긴다.
- [ ] 묻는 동안 목록 태그에 `확인 필요`가 붙고, 노란 바닥 줄에 글과 [멈추기] · [계속 진행]이 보인다. 실행 중 전달이 안 되는 에이전트에서는 글의 둘째 문장이 "멈추거나 답이 없으면 보고서 없이 끝납니다."다.
- [ ] OS 알림이 한 번 뜨고 버튼이 없으며, 누르면 그 진단이 열린다. 창이 강제로 앞에 뜨지 않고 트레이 수는 바뀌지 않는다.
- [ ] [계속 진행]은 상한을 10분 늘리고 새 상한 5분 전에 다시 묻는다. 합계 60분이 되는 때에는 묻지 않고 60분에 [멈추기]처럼 처리한다. 전달이 되는 에이전트에게 "10분이 더 있다"가 간다.
- [ ] [멈추기]: 전달이 되는 에이전트에게 마무리 메시지가 가고, 5분 안에 결과가 나오면 보통의 검토 대기 보고서가 되며, 안 나오면 끊고 진단 실패(시간 초과)가 된다. 그동안 바닥 줄은 "보고서를 마무리하는 중입니다. 5분 안에 끝납니다."다. 전달이 안 되는 에이전트는 바로 끊고 진단 실패(시간 초과)가 된다.
- [ ] 답이 없으면 상한에 [멈추기]와 똑같이 처리된다.
- [ ] 재현하던 진단이 시간 초과로 실패했으면 [재현 없이 다시 시도]가 보인다. 읽기 전용으로 돌고 그 보고서의 재현 칸은 "불가(시간 초과)"다.
- [ ] 다시 진단에도 같은 규칙이 적용되고, 다시 켜서 처음부터 도는 실행은 상한을 처음부터 센다.
- [ ] 가짜 시계와 가짜 실행기(전달 능력 켬·끔)로 위 갈래가 테스트된다.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`가 통과한다.
