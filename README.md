# Stardraft

Flow에서 나를 멘션한 업무에 답할 초안을 내 PC의 Claude Code 또는 Codex로 만드는 앱입니다. 초안을 검토하고 수정한 뒤, 직접 게시할 수 있습니다.

## 사용 전에 준비할 것

- Flow 개인 키(Flow 계정을 연결할 때 사용)
- 내 PC에 설치하고 로그인한 Claude Code 또는 Codex
- 답변의 근거를 찾을 로컬 코드 저장소 폴더

## 처음 사용하기

1. 앱을 열고 Flow 개인 키를 입력해 내 계정을 연결합니다.
2. 사용할 에이전트를 선택하고 연결 확인을 마칩니다.
3. 에이전트가 읽을 코드 저장소 폴더를 지정합니다.
4. 멘션이 도착하면 초안과 근거를 확인하고, 필요한 내용을 수정한 뒤 **게시**합니다.
