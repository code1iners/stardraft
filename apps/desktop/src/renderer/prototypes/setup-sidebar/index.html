Stardraft · 설정

레퍼런스와 초안의 전제
  • Linear — 설정 탐색과 사이드바: 메뉴의 밀도와 정보 계층 참고. Stardraft의 기존 180px 폭·색상 유지.
  • Carbon — 진행 상태와 항목 이름: A·B·C의 상태 표현 참고. 필수 설정 순서는 강제하지 않음.
  • Radix — 접기·펼치기: D의 요약과 상세 분리 참고.
  • Radix — 팝업: E의 필요할 때 보는 상세 패널 참고.
  • 실제 제품 화면을 복제한 것이 아닌, 위 패턴을 조합한 Stardraft용 제안입니다. 계정·폴더·감지는 모두 예시이며 실제 변경은 없습니다.
  • 선택 후 기존 ‘상단 띠’ 문서와 구현을 함께 변경합니다. 감지 시작 이후 실제 앱은 설정 창을 닫습니다. 이 초안에서는 결과만 모의 표시합니다.
