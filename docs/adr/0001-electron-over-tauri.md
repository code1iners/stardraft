# Tauri 대신 Electron으로 데스크톱 앱을 만든다

트레이에 상주하는 작은 앱에는 설치 크기가 작은 Tauri v2를 흔히 고른다. 미서명 배포를 조사할 때도 처음에는 Tauri가 유리해 보였다. Electron 42 이상 문서에 macOS 알림과 로그인 항목에는 코드 서명이 필요하다고 적혀 있었기 때문이다.

그러나 2026-10-15에 macOS 27과 Apple Silicon에서 확인해 보니, ad-hoc 서명만 한 Electron 44 앱에서도 세 가지가 실제로 동작했다. 알림 표시, 알림 클릭 전달, 로그인 시 자동 시작이다. 그러자 남은 차이는 크기와 언어뿐이었다.

Electron을 고르면 두 가지를 얻는다.
- 핵심 로직(폴링, CLI 실행, 게시, 키 보관)을 Rust가 아닌 개발자의 주력 언어 TypeScript 하나로 쓸 수 있다.
- 실기로 검증된 경로를 쓸 수 있다.

이 두 가지를 설치 크기(런타임만 124~151MiB)보다 무겁게 봤다.

## Consequences

- ad-hoc 서명으로 알림과 로그인 항목이 동작하는 것은 문서가 보장하는 동작이 아니다. 그래서 Electron 메이저를 올릴 때마다 미서명 macOS 점검을 다시 돌린다. 점검 항목은 설치 경로, 알림 표시, 알림 클릭, 자동 시작이다.
- Electron은 8주마다 메이저가 나오고 최신 3개 메이저만 지원한다. 그래서 자주 올려야 한다.
