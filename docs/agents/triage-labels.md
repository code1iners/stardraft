# Triage 라벨

Skill들은 다섯 가지 기본 triage 역할로 말한다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 대응시킨다. 로컬 마크다운 트래커에서는 이 문자열을 각 이슈 파일의 `Status:` 줄에 적는다.

| mattpocock/skills의 라벨 | 이 트래커의 라벨  | 의미                                   |
| ------------------------ | ----------------- | -------------------------------------- |
| `needs-triage`           | `needs-triage`    | 관리자가 검토해야 하는 이슈            |
| `needs-info`             | `needs-info`      | 보고자에게 추가 정보를 기다리는 중     |
| `ready-for-agent`        | `ready-for-agent` | 명세가 충분해 AFK 에이전트가 맡을 수 있음 |
| `ready-for-human`        | `ready-for-human` | 사람이 구현해야 함                     |
| `wontfix`                | `wontfix`         | 처리하지 않음                          |

Skill이 역할을 언급하면(예: "AFK-ready triage 라벨을 붙여라") 이 표에서 대응하는 라벨 문자열을 쓴다.

실제로 쓰는 어휘가 다르면 오른쪽 열을 고친다.
