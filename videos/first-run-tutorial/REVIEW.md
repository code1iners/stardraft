# 검토 기록

## 제작 판단

합의한 ‘질문 한 건의 여정’을 제작했다. 결과에서 거꾸로 설명하는 방향과 연결도 중심 방향은 제작하지 않았다. 실제 앱의 React 컴포넌트·스타일을 가상 상태로 촬영해 화면의 버튼·문구를 유지했다. 설치 과정은 제외하고 필수 설정과 첫 검토·게시를 보여 준다.

## 검토와 수정

- 전체 장면의 시작·중간, 모든 장면 경계의 전후, 휴대전화 폭 축소본을 확인했다.
- 독립 시각 검토에서 P0는 없었고 에이전트 연결 진행, 상위 폴더 선택 의미, 작은 근거 글자가 P1로 나왔다.
- t=34–42초: 실제 에이전트 컴포넌트의 찾기·버전·로그인·작동 확인 상태를 순서대로 보여 주도록 수정했다. 이 칸을 열면 자동 확인한다는 안내를 추가했다.
- t=44.6–48.1초: work/account-api 구조와 선택할 상위 폴더를 설명하는 보조 그림을 추가했다.
- t=93–102초: 실제 근거 화면을 확대하고 파일 위치까지 카메라를 이동했다. 99초 프레임에서 설명과 reset-token.ts의 12번째 줄이 읽히는 것을 확인했다.
- t=117.1–122.1초: 5→4→3→2→1초를 실제 앱 PostingFooter에서 생성한 화면으로 각각 1초씩 보여 준다. 편집한 문장이 유지되는지 확인했다.
- t=130–142초: 시험 화면은 실제 앱의 ‘시험 끝내기’를 사용하며 게시 장면으로 이어지지 않는다.
- 안내 글자는 28px 이상, 자막은 31px로 조정했다. 화면에는 공식 제품명, 음성에는 발음하기 쉬운 표기를 사용했다.

## 자동 검사

최종 소스의 `source/check-final.json` 기준 HyperFrames check 통과. 린트·런타임·레이아웃·대비 오류 0. 모션 수치 감사는 CLI 기본 설정에서 비활성 상태이며, 정지 프레임과 경계 이미지의 시각 검토로 보완했다.

남겨 둔 경고:

- `timeline_track_too_dense` 2개: 에이전트 5단계와 게시 5초 카운트다운을 같은 장면 안에서 비교하기 위해 유지한다.
- `dead_stretch`: 설명을 듣고 앱의 글을 읽도록 3초 이상의 고정 구간을 둔 장면들이다. 장식용 움직임을 넣어 수치를 피하지 않았다.
- 글꼴은 단일 HTML 인라인 용량 한도를 넘지만 프로젝트의 `assets/fonts/`에서 정상 로드된다. 전달 시 에셋 폴더를 함께 보존해야 한다.

## 검증 경계

앱 화면은 실제 소스를 사용하지만 이 영상은 가상 데이터로 연출한 튜토리얼이다. 실제 설치본의 macOS 권한 창·실제 Flow 게시·실제 에이전트 실행을 촬영한 증거는 아니다. 음성·음악은 파일의 존재·길이·레벨을 측정하며 사람이 전체 음성을 청취한 검증은 하지 않았다. 내레이션 발음의 자연스러움은 사용자 시청 후 조정할 수 있다.

가장 약한 구간은 8초 안에 준비물과 세 설정을 설명하는 초반이다. 사용 흐름의 개요라는 합의에 맞춰 유지했다. 실제로 따라 하는 별도 가이드가 필요하면 설정 단계를 더 길게 분리하는 편이 낫다.

## 최종 출력 확인

- `renders/stardraft-first-use.mp4`: H.264, 1920×1080, 30fps, 150.000초, 8,725,324바이트.
- 오디오: AAC, 48kHz, 스테레오. 전체 통합 음량 -14.68 LUFS, true peak -1.83 dBTP로 측정되어 클리핑 없이 목표 범위에 들어간다.
- 완성 MP4를 디코딩한 99초 근거 장면과 119.5초 게시 취소 장면을 확인했다. 소스 미리보기와 같은 내용이며 편집한 문장이 카운트다운 중에도 유지된다.
- 16개 장면이 0–150초를 빈틈없이 덮고 음성 31개가 모두 해당 장면 범위 안에 들어가는 것을 검사했다. 한국어 SRT의 제품명·숫자 표기도 확인했다.
- 출력 검증은 파일·프레임·오디오 수치 검증이며 전체 사람 청취는 포함하지 않는다.

- 99초 근거 화면과 119.5초 게시 취소 화면을 다시 캡처해 파일 위치·수정 문장·남은 시간·취소 버튼·자막을 확인했다. 문서·외부 에셋의 불필요한 공백만 정리했으며 라이선스 문구와 실행 코드는 유지했다.
- 이번 정리는 영상 재렌더·실제 앱 실행·실제 Flow 게시·전체 사람 청취 검증을 포함하지 않는다.
