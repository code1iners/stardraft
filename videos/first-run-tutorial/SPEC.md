# Stardraft 최초 사용 튜토리얼

- 기준: HEAD `fcbad7a30d7ac958aa00a8106c340939c2900f7f`. 앱의 미커밋 개발 실행 명령 변경은 영상 내용에 포함하지 않는다.
- 목표: Flow와 로컬 코딩 에이전트에 익숙한 개발자가 설치 후 첫 멘션의 초안을 검토하고 게시하는 흐름을 이해한다.
- 산출물: HyperFrames, 1920×1080, 30fps, 150초 = 4,500프레임, MP4 + 한국어 SRT + 편집 소스.
- 표현: 실제 앱 React 컴포넌트와 CSS를 가상 데이터로 렌더링한 화면. 동작과 대기 시간은 설명 목적에 맞게 압축. 실제 Flow 호출·게시 없음.
- 예제: 이지원 → 김민수에게 비밀번호 재설정 링크 유효 시간 질문. 가상의 account-api 코드에서 30분을 확인. 이 값은 Stardraft 자체의 기능 수치가 아니다.
- 색: 배경 #edf1f5, 화면 #ffffff, 글 #1d2024, 강조 #2160c4, 완료 #1e7438. 앱 토큰을 유지한다.
- 글꼴: Noto Sans KR 400/600/700, 제목 64px, 설명 32px, 자막 34px. 화면 원문은 확대해 핵심 버튼이 읽히도록 한다.
- 배치: 96px 액션 여백, 핵심 글자와 자막은 192px 이상의 좌우 여백. 자막은 y=890~955. 제목과 화면은 서로 겹치지 않는다.
- 모션: 화면 등장 18프레임 power4.out, 커서 이동 24프레임 power2.inOut, 클릭 6프레임, 강조 12프레임. 설명을 읽는 동안 제목은 고정한다. 반복 부유/장식 애니메이션 없음.
- 사운드: macOS Yuna 한국어 합성 음성, 낮은 음량의 Wallpaper(Kevin MacLeod, CC BY 4.0), 클릭 및 알림 효과음. 유료 서비스 호출 없음.
- 금지: 실제 계정·키·회사 데이터, 자동 게시로 보이는 연출, 시험에서 게시로 이어지는 연출, 채팅 감지를 지원한다는 설명, 배경 네온/그라디언트/장식 입자, 작은 화면을 장시간 방치하는 장면.

## 사실 확인 경계

온보딩·설정·검토 화면은 HEAD 소스에서 생성한다. macOS 메뉴 막대와 Flow 질문·게시 결과는 설명용 재현이라고 화면에 표기한다. 알림 권한 창의 정확한 시점은 설치본 실측이 없으므로 특정 시점의 OS 권한 창을 연출하지 않는다. 최초 감지 시작 시 과거 멘션을 가져오지 않는 점, 시험이 실제 사용량을 쓰지만 게시하지 않는 점을 설명한다.
