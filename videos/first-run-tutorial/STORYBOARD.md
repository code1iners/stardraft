# 내레이션과 장면 구성

## 0–10초 · 이 멘션, 코드에서 답을 찾으려면

동료가 비밀번호 재설정 링크의 유효 시간을 물었습니다.

스타드래프트에서 코드에 근거한 초안을 만들고, 직접 검토해 게시해 보겠습니다.

## 10–18초 · 메뉴 막대의 별에서 시작합니다

설치한 앱을 켜고, 맥 메뉴 막대의 별 아이콘을 누릅니다.

설정 열기에서 처음 필요한 세 가지를 연결합니다.

## 18–26초 · 준비할 것은 세 가지입니다

플로우 개인 에이피아이 키, 로그인된 로컬 에이전트, 그리고 코드 저장소가 필요합니다.

키 발급과 에이전트 설치는 미리 마쳐 주세요.

## 26–34초 · 내 Flow 계정을 확인합니다

플로우 계정에 내 개인 키를 붙여 넣고, 확인을 누릅니다.

연결된 이름과 소속이 내 계정인지 확인하세요.

## 34–42초 · 로그인된 Claude Code를 연결합니다

에이전트에서는 찾기, 버전, 로그인, 작동 확인이 진행됩니다.

작동 확인은 실제 사용량을 조금 씁니다. 코덱스도 선택할 수 있습니다.

## 42–50초 · 저장소가 모인 작업 폴더를 고릅니다

저장소에서 폴더 추가를 누르고, 코드 저장소가 모인 상위 폴더를 고릅니다.

연결이 없는 멘션은 여기서 찾은 저장소를 바탕으로 처리합니다.

## 50–60초 · 이제 새 멘션을 기다립니다

필수 설정을 마쳤다면 감지 시작을 누릅니다.

이때부터 새 업무 멘션을 감지합니다. 과거 멘션을 자동으로 가져오지는 않습니다.

## 60–70초 · 동료가 새 업무 멘션을 보냅니다

동료가 업무 댓글에서 나를 직접 지목해 질문합니다.

채팅이나 담당자 지정이 아닌, 나를 직접 지목한 새 업무 멘션이 대상입니다.

## 70–80초 · 관련 저장소에서 초안을 만듭니다

연결된 저장소가 없으면 작업 폴더에서 적절한 저장소를 고릅니다.

로컬 에이전트가 관련 코드를 읽고, 멘션에 답할 초안을 만듭니다.

## 80–90초 · 초안이 나오면, 먼저 읽어 봅니다

알림이나 별 아이콘의 숫자로 초안이 준비된 것을 알 수 있습니다.

열린 화면에서 원문과 에이전트가 이해한 요구, 답변 초안을 비교합니다.

## 90–102초 · 근거 번호로 답의 출처를 확인합니다

초안 문장 옆의 근거 번호를 누르면, 설명과 파일 위치를 확인할 수 있습니다.

이 예제에서는 링크가 삼십 분 동안 유효하다는 코드 근거를 확인합니다.

## 102–114초 · 내가 보낼 문장으로 다듬습니다

문장을 눌러 동료에게 보낼 표현으로 직접 수정하고, 받는 사람도 확인합니다.

편집하면 초안의 근거 번호는 숨겨집니다. 근거 확인을 먼저 마쳐 두세요.

## 114–125초 · 게시 전, 마지막으로 확인합니다

내용이 맞으면 게시를 누릅니다.

오 초 동안은 취소할 수 있습니다. 시간이 지나면 내 이름으로 플로우에 게시됩니다.

## 125–130초 · 동료에게 내 답변이 도착합니다

게시되는 것은 답변 본문이며, 코드 근거는 포함되지 않습니다.

## 130–142초 · 혼자라면, 최근 멘션으로 시험합니다

새 멘션을 기다리지 않고 연습하려면, 최근 멘션으로 시험을 누르세요.

실제 에이전트 사용량은 쓰지만 플로우에는 게시하지 않습니다. 시험 끝내기로 마칩니다.

## 142–150초 · 근거를 확인하고, 내 답변으로 게시하세요

설정을 마치고, 근거를 확인하고, 내 답변으로 다듬어 게시하세요.

지금은 최근 멘션으로 시험부터 시작해 보세요.
