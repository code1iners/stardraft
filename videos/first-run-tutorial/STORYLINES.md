# 이야기 방향

사용자가 이미 합의한 브리프를 우선하므로 추가 방향 선택을 요청하지 않고 A를 제작한다.

- **A. 질문 한 건의 여정 — 제작:** 동료의 구체적인 질문을 시작점으로 설정·감지·코드 근거·검토·게시를 따라간다. 실제 앱 화면을 확대하고 커서가 다음 동작으로 시선을 이끈다. 낮은 배경음과 한국어 내레이션.
- **B. 답변에서 거꾸로 — 미제작:** 게시된 답변에서 시작해 근거와 설정으로 역추적한다. 첫 사용자가 따라가는 순서와 달라 이번 범위에서는 선택하지 않는다.
- **C. 코드와 멘션의 연결도 — 미제작:** Flow·앱·로컬 저장소를 하나의 연결도로 확장한다. 원리 설명에 유리하지만 실제 사용 화면을 익히는 목적에는 보조 장면으로만 사용한다.
